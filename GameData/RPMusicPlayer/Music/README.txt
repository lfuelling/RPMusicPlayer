Put your music here.

Wave files are played out of the box, because wave is the only format Kerbal
Space Program 1's audio engine is known to decode. Sub folders are scanned too,
so you can organise by artist.

Other formats can be added with the EXTENSIONS setting in the plugin's
configuration file, but they are not guaranteed: a format the engine refuses
loads as an empty clip and the track stops instead of playing.

Tags are read when present, so the browser can sort by artist, album, genre or
title. Files without tags show their file name instead.
